# battery-SOH-RUL
基于MIT锂电池数据（124 颗 LFP 电池），融合电压、电流、温度、dQ/dV及容量变化等特征，搭建双向LSTM、CNN、MoE等模型预测锂电池的容量和剩余使用寿命

电池数据是开源的，在网上能直接下载，我这里不提供源数据，但是 'MIT说明.md' 有我对于此数据集的预处理介绍和使用方式。

其余两个 md文档 是对应名字的代码文件的介绍。

# 注意！！！
我没有对代码文件中的数据地址进行修改，我用的是绝对文件地址，如果你自己下载了数据集并处理后放在了别的位置，请使用代码时修改成你自己的数据路径！

在测试集的19颗电池上，BiLSTM_MoE 模型预测的容量MAE达0.0055 Ah、MAPE为0.54%；相较BiLSTM基准MAE 0.0068 Ah降低19.1%。以每电池最大容量的80%为阈值定位EOL，RUL窗口级/电池级MAE分别为0.89/1.32 cycles
